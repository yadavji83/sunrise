# Hotel Sunrise website

The finished static website is in `dist/` and is ready for GitHub Pages. No database, build command, or server-side runtime is required.

## Publish with GitHub Pages

1. Create a GitHub repository and upload/push this project.
2. Use `main` as the repository's default branch.
3. In the GitHub repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **GitHub Actions** as the source.
5. Push to `main`, or run **Deploy Hotel Sunrise to GitHub Pages** from the Actions tab.

The included workflow publishes only the contents of `dist/`. Relative asset paths are already compatible with both user and project GitHub Pages URLs.
